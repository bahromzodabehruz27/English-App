# English-App 📚

A comprehensive, interactive web application for learning English language. This app provides multiple learning modules including vocabulary, grammar, pronunciation, reading comprehension, and listening exercises.

## Features

### 🎯 Vocabulary Builder
- Interactive flashcards with word definitions and examples
- Flip cards to reveal meanings and usage
- Track words learned
- 8 carefully selected vocabulary words with real-world examples

### 📖 Grammar Exercises
- Multiple-choice grammar questions
- Instant feedback with explanations
- Covers various grammar topics (verb tenses, conditionals, passive voice)
- Track your grammar accuracy

### 🗣️ Pronunciation Practice
- Phonetic transcriptions for proper pronunciation
- Text-to-speech audio playback
- Detailed pronunciation tips
- Practice common challenging words

### 📝 Reading Comprehension
- Engaging reading passages
- Comprehension questions
- Score tracking
- Improve reading skills with real-world content

### 🎧 Listening Exercises
- Audio-based questions using text-to-speech
- Multiple-choice answers
- Track listening comprehension progress
- Practice understanding spoken English

### 📊 Progress Tracking
- Monitor words learned
- Track scores across all modules
- Visual progress indicators
- Overall performance metrics
- Local storage to save your progress

## How to Use

1. **Open the App**: Simply open `index.html` in a web browser
2. **Navigate**: Click on any section button in the navigation bar
3. **Practice**: 
   - **Vocabulary**: Click "Next Word" to cycle through flashcards, "Flip Card" to see definitions
   - **Grammar**: Select an answer and click "Check Answer" to see if you're correct
   - **Pronunciation**: Click the play button to hear the word pronounced
   - **Reading**: Read the passage and answer the questions
   - **Listening**: Click play to hear the audio, then answer the question
4. **Track Progress**: Visit the Progress section to see your statistics
5. **Reset**: Use the "Reset Progress" button to start fresh

- **HTML5**: Structure and semantic markup
